# Laboratory 01 VALDEZ,S – Welcome to the Cloud

Mission Overview

In this laboratory, I was introduced to the basics of working with a cloud-based Linux environment. I used KillerCoda to access Ubuntu 24.04 and practiced some of the basic tasks that a cloud infrastructure engineer needs to know, such as managing users, checking system information, and organizing files.

Learning Objectives

Access a Linux environment through the cloud.
Learn and practice basic Linux commands.
Create and manage a Linux user account.
Check the computer's system information.
Create and organize files and folders.
Create a GitHub repository for my cloud computing activities.
Use Markdown to document my work.
Take screenshots to show the activities I completed.

Activities Completed

Accessed Ubuntu 24.04 through KillerCoda.
Created and configured a new Linux user with sudo access.
Logged in and checked the username, directory, and hostname.
Viewed basic system information such as CPU, memory, and disk space.
Created and organized the required files and directories.
Set up a Cloud Computing Portfolio on GitHub.
Captured screenshots as evidence of the completed activities.

Linux Commands Used

Command	Purpose
whoami	Check the current user
pwd	Show the current directory
hostname	Check the system name
sudo adduser	Create a new user
sudo usermod	Modify a user
su	Switch users
cat	View file contents
uname	Check system information
lscpu	View CPU details
free	Check memory usage
df	Check disk space
cd	Change directories
mkdir	Create directories
touch	Create files
nano	Edit files

Summary

This laboratory gave me my first hands-on experience with a cloud-based Linux system. I learned how to create a user, navigate through directories, check system resources, and manage files using the terminal. I also learned how to organize my work in GitHub and document the activities with screenshots. Overall, the activity helped me become more comfortable with Linux and gave me a better understanding of some of the basic tasks involved in cloud computing.
