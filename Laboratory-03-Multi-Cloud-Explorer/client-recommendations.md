# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for a startup because it provides a broad range of services that can support an application as it grows. The startup can begin with relatively simple infrastructure and increase resources as demand increases. AWS also provides services for computing, storage, databases, networking, and application development.

### Recommended Services

* Amazon EC2 – virtual computing
* Amazon S3 – object storage
* Amazon RDS – relational database
* Amazon VPC – networking

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the recommended platform because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's enterprise ecosystem and identity services. This can help the university extend its existing environment into cloud infrastructure while maintaining familiar Microsoft technologies.

### Recommended Services

* Azure Virtual Machines
* Microsoft Entra ID
* Azure Virtual Network
* Azure Blob Storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is a strong choice for an AI research company because it provides services and infrastructure designed for artificial intelligence and machine learning workloads. Google Cloud also provides specialized AI infrastructure, including GPU and TPU resources in certain locations. The company can combine compute infrastructure, data storage, and AI services to develop and operate research workloads.

### Recommended Services

* Compute Engine
* Google Cloud Storage
* Vertex AI
* Google Kubernetes Engine

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable choice for a global e-commerce company because it provides scalable computing, storage, networking, databases, and load-balancing capabilities. A global online shopping platform requires high availability and the ability to respond to changing traffic levels. AWS services can be combined to create a distributed architecture capable of handling large workloads.

### Recommended Services

* Amazon EC2
* Elastic Load Balancing
* Amazon S3
* Amazon RDS
* Amazon CloudFront

---

# Multi-Cloud Decision Matrix

| Business Requirement    | Recommended Platform | Justification                                                             |
| ----------------------- | -------------------- | ------------------------------------------------------------------------- |
| Startup Company         | AWS                  | Broad services and scalable infrastructure can support a growing startup. |
| Enterprise Organization | AWS                  | Large service portfolio and enterprise infrastructure capabilities.       |
| Microsoft Environment   | Azure                | Strong integration with Microsoft technologies and identity services.     |
| AI / Machine Learning   | Google Cloud         | Strong AI/ML capabilities and specialized infrastructure.                 |
| Kubernetes Deployment   | Google Cloud         | Google Kubernetes Engine provides managed Kubernetes.                     |
| Global Web Application  | AWS                  | Broad global infrastructure and scalable application services.            |
