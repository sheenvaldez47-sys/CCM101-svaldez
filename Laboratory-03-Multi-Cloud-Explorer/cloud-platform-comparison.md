## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is commonly recognized for its very broad portfolio of cloud services. Its services cover computing, storage, networking, databases, security, analytics, machine learning, and many other categories.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations already using Microsoft technologies. It integrates naturally with technologies such as Windows Server, Microsoft 365, and Microsoft identity services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes workloads. Google Cloud provides AI and machine-learning infrastructure as well as Google Kubernetes Engine for managed Kubernetes deployments.

### 4. Which cloud platform would you personally choose and why?

I would choose Google Cloud Platform because I am interested in artificial intelligence, machine learning, and containerized applications. Google Cloud provides Compute Engine, GKE, and AI-related services that can support these types of workloads.
